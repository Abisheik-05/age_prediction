# Age Prediction AI

AI-powered age prediction system that estimates a person's age from facial images using computer vision and deep learning.

## Features

- Upload image for age prediction
- Live webcam capture
- Responsive modern UI
- Real-time prediction workflow
- Backend image processing
- AI-based facial age estimation

## Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express
- Multer

### AI/ML
- Deep Learning
- Computer Vision
- Age Estimation Model

## Project Workflow

Image Upload / Webcam Capture
↓
Frontend (React)
↓
Backend (Node.js + Express)
↓
AI Model
↓
Predicted Age
